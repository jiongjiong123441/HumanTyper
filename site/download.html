下载 HumanTyper.exe

文件托管在 GitHub。下载很慢或打不开时，可以到 GitHub 发布页 重试，或者 从源码自己编译。

第一次打开

  1. 一
    双击 HumanTyper.exe

    放在哪个文件夹都行。设置保存在 %APPDATA%\HumanTyper 里，不会弄乱别处。

  2. 二
    如果 Windows 弹出“已保护你的电脑”

    这是因为程序没有付费代码签名。点“更多信息”，再点“仍要运行”。

  3. 三
    如果杀毒软件报毒

    程序会模拟键盘输入并监听全局按键（用来发现你接管了键盘），部分杀毒软件会因此误报。源码完全公开，可以先用下面的校验值核对文件。

核对文件

下载后可以比对 SHA-256，确认文件和 GitHub 上发布的完全一样。

正在从 GitHub 读取
Get-FileHash .\HumanTyper.exe -Algorithm SHA256

在 PowerShell 里进入下载文件夹，运行上面这行，输出的 Hash 应与上方一致（大小写不同没关系）。

系统要求

  • 系统Windows 10 或 Windows 11
  • 运行环境.NET Framework 4.8，Windows 10 和 11 已自带
  • 安装不需要，单文件直接运行
  • 驱动级模式可选，需要在程序里一键安装 Interception 驱动并重启
  • 价格免费，MIT 协议开源
